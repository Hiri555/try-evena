# SS7 — Épisode 3 · « LE DÉCODAGE »

Dernier volet de la série **Signalisation Sémaphore N°7**.
Réalisation et signature : **Big Magass**.

**8 min 36 · 1920×1080 · 24 i/s · 12 393 images · −14,2 LUFS / −1,5 dBTP**

Il couvre les deux morceaux que les épisodes 1 et 2 laissaient de côté :

- **§15 — la gestion du réseau sémaphore**, le deuxième groupe de fonctions
  du niveau 3 (canaux · trafic · routes), les ordres PCO/PCA/PUO/PUA/RCO/RCA
  et la congestion ;
- **TD3 — le décodage d'une trame ISUP de 38 octets**, résolu question par
  question. Le dossier le dit : « exactement le format de ton évaluation ».

| Dossier | Contenu |

| `render/` | le code de rendu — une seule grille d'octets, réutilisée du ch. 06 au 10 |
| `audio/` | mesure des repères de voix, sous-titres, montage et mixage |
| `img/` | les images génératives qui servent de plans de respiration |
| `VO_EP3.md` | le texte dit par la voix off |
