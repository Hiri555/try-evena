QUESTION 2 · LE TRAJET
le GPS, ici, c'est le SCS
SCS = 7  =  0 1 1 1
BIT 3    BIT 2    BIT 1    BIT 0
PSA  ·  bit 0 = 1  →  XXX1  →  PTS6
PTS6  ·  bit 1 = 1  →  XX1X  →  PTS2
PTS2  ·  bit 1 = 1  →  XX1X  →  PTS3
PTS3  ·  bit 0 = 1  →  XXX1  →  PSB
PSA → PTS6 → PTS2 → PTS3 → PSB
le piège : PSA n'est relié qu'à PTS1 et PTS6 — on avance carrefour par carrefour
